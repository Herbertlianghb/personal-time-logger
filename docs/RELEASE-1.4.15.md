# v1.4.15-rc.1 试用版

日期：2026-11-01（UTC+8）。桌面程序版本 **1.4.15**，解释器契约 **1.2.3**。继续作为预发布供试用；新用户从零接入的完整流程尚未验证。

## 相比 v1.4.7-rc.1

- 独立输入窗共享草稿和提交队列，可钉选置顶；紧凑、可拖动的“随手记”和图钉栏，去掉系统标题栏。
- 主记录窗维持紧凑尺寸；今日工作、学习进度读取飞书时段标准，缺失、重叠和过期缓存不亮达标灯。
- 不接飞书的独立实例可保存原文、按日期回看和统计条数。新增按需整理：本人电脑上的 Codex 读取指定日期，生成有来源的候选，经校验写回自己的实例后显示分类时间线和有依据的时长。无需定时任务；已有实例须由管理员显式启用，见[按需整理](MANUAL-ORGANIZATION.md)。
- 解释器支持有语境的三位、四位时刻简写，保留来源、修订和服务端独立校验。

## 使用与升级

Windows 附件包含 Python、Qt 运行时和第三方许可；完整解压后运行“安装.vbs”。升级保留 `%USERPROFILE%\.personal-time-logger`、Credential Manager 设备私钥、草稿和队列。发布不意味着已自动升级任一用户电脑或服务端。

首次使用需要自己的服务器或经授权提供的独立实例。飞书模式使用自己的飞书应用与兼容 Base；不接飞书时按[桌面原文模式](DESKTOP-ONLY.md)部署。按需整理仍需本人 Codex 可用，服务器不会自行解释。缺失起止不生成工时，不把原文保存当成整理或飞书归档成功。
