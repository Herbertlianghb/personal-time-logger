# v1.4.7-rc.1 试用版

日期：2026-10-29。桌面版本为1.4.7，模型解释契约为1.2.2，以v1.4.7-rc.1预发布供试用。README提供Agent安装与接入提示词，首次使用条件见下文。

本次沿用已构建并检查的1.4.7桌面程序，只更新分发文档与文件清单，没有重新构建或恢复已暂停的新用户测试。旧本地v1.4.7标签不移动。

## 相比1.4.0的主要变化

- 深绿色悬浮入口支持拖动贴边、悬停展开和点击展开／收起；鼠标移开后保存草稿并收回入口，热力图同步参与收起。输入法组字、菜单操作和“保持展开”等保护保留。
- 热力图提供每日、每周、累计视图，本月或近一年范围，以及累计记录时长、记录日日均、单日最多和连续有记录天数。
- 已保存估算起止的记录参与区间并集，角标或分段说明估算成分；缺少起止继续保留缺口，不将记录经过时间当成净人工时长。
- 输入框取得焦点或进行拼音组字时隐藏示例文字，保留中文选字期间不发送的行为。
- 模型解释导入前检查来源和时间，按错误类别最多修正一次；正式Base的纯分类选项变化刷新缓存，字段结构变化及远端人工修改仍受冲突保护。

## 使用条件

Windows分发包包含Python和Qt运行时；完整解压后运行`安装.vbs`，无需日常安装开发环境。此入口是安装脚本，不是MSI或签名安装器。

首次使用需要自己的Linux服务器、可信SSH主机公钥和设备登记；服务端接收飞书消息需要自己的飞书自建应用与本人身份。当前没有公共托管服务器或独立离线账本模式。模型解释、聊天镜像与正式Base写入分别配置；热力图的正式数据需要自己的兼容Base。最小流程可关闭模型、Base和Notion派生功能，只保存原文并取得服务器回执。

普通用户见[安装与首次配置](SETUP.md)；部署者见[服务端说明](SERVER.md)；Agent见[配置指南](AGENT-SETUP.md)和[可复制提示词](AGENT-PROMPTS.md)。
