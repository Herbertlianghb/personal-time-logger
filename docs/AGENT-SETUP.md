# Agent 安装与接入指南

适用于 Codex App、Codex CLI 或能读写用户本机文件的 Claude。Agent 使用自己的工具，按当前代码和用户实际环境操作；不要假设具备维护者的账号、路径、服务器或已保存配置。可复制入口见 [AGENT-PROMPTS.md](AGENT-PROMPTS.md)。

## 必须读的最小文档

- [SETUP.md](SETUP.md)：Windows 包、首次绑定、数据位置和失败处理。
- [SERVER.md](SERVER.md)：组件职责、自己的飞书授权、Linux、设备登记、可选模型/Base。
- [CONFIGURATION.md](CONFIGURATION.md)：配置字段、固定字段名和边界。
- 实际代码：`desktop_setup.py`、`desktop_app.py`、`desktop_transport.py`、`desktop_bridge.py`、`service.py`。仅配置模型时加读 `remote_worker.py`、`model_runner.py`；仅配置Base时加读 `base_adapter.py`。

源码包同时提供 `config/config.example.json`、`client.example.json`、`device.example.json`、`ssh-config.example` 和 `field-contract.example.json`。模板没有可用账号。若手中只有 Windows 包且需要部署服务器，取得同版本公开源码包；不要在作者的私人交付目录寻找凭据。

## 工作边界

1. 确认用户要安装新环境还是接入已有环境，明确当前机器、源码根目录、安装包和自己的服务器。读取必要目标后，完成可回退的本地配置；不擅自安装订阅、创建任务、迁移数据库或发布服务。
2. 发现现有 `device.json`、Credential Manager 身份或数据库时保留。配置缺失不等于凭据已丢失；不要删库、重绑或创建第二份活动数据根。不要导入维护者历史记录。
3. 用户的登录、管理员审批和可信主机公钥确认不能假装自动完成。需要用户参与时，每次只给一个具体动作，说明完成标志；等其反馈后继续。不要一次要求多个账号、密钥和截图。
4. 秘密只写入用户自己的受限配置或系统凭据存储，不在终端回显，不写入 README、日志、截图、Git 或聊天。桌面只保存设备私钥，服务端保管 App Secret，模型登录态留在本机。设备公钥可以交给自己的服务器管理员。
5. 采用现有 Python/PySide6/SSH 方案，不为安装重写架构。官方权限、CLI版本和账号能力以当前环境核实；说明书没有授权自动改变用户生产环境。

## 执行顺序与完成标志

| 阶段 | 动作 | 可认定完成的证据 |
| --- | --- | --- |
| 读取环境 | 检查用户指定文件、已有配置是否存在，不输出秘密 | 已识别新装/升级/缺配置状态 |
| 最小服务端 | 按SERVER配置自己的飞书应用、本人open_id和数据路径 | 授权运行后服务可接收本人消息；未知授权仍明确保留 |
| Windows安装 | 使用同版本完整分发包；无包时在授权后源码构建 | 安装入口指向自己的版本，首次配置可打开 |
| 设备接入 | 可信主机公钥→本机生成身份→服务端登记/forced command→保存 | 自己的设备收到服务器保存回执 |
| 首次时间记录 | 仅发送用户明确愿意保存的内容 | 原文、稳定ID与报告时刻符合输入，确认服务器保存 |
| 可选模型 | 配置自己的CLI、SSH和outbox，按授权运行一次 | worker成功或明确的缺失条件；不能只看模型文字 |
| 可选Base | 实时schema匹配，用户授权写入后启用 | 正式写后回读匹配，冲突不覆盖人工修改 |

测试、试运行、构建和额外校验按用户当次授权执行。先说明必要范围和原因，再请求一次授权；获准后不自行增加轮次。读取配置目标、命令退出状态与关键输出是基本操作，不能据此声称完整验证通过。没有执行时写“未运行验证”；运行了部分时列出实际证据与未验证范围。

首次保存可在 `parse=false/base_sync=false/notion_sync=false` 下完成。不要因为模型尚未配置，把一个纯记录用户引向购买模型订阅或注册额外任务。若用户希望完整自然语言整理，再继续其已授权的模型/Base接入。

## 常见阻塞

- 没有服务器：可配置本地说明与模板，服务端需要用户选择自己的主机；不能接入维护者服务器或用离线队列冒称完整账本。
- 不知道本人open_id：按同应用授权工具确认本人，不能填示例、用其他app ID或取消身份过滤。
- SSH拒绝：核对可信主机公钥、端口、固定`time-logger`用户、设备登记和forced command，不禁用校验、不索取设备私钥。
- CLI版本/模型不可用：当前解释器只支持代码指定的Codex版本/模型；保留原文，说明阻塞。Claude安装Agent不等于Claude解释器。
- Base字段不兼容：给出具体缺字段/类型/选项，不自动重建表、不写公式、不复制作者快照。
- 需要验证首条记录：先取得用户对实际保存内容和范围的授权，不能用“测试”理由向真实业务表写虚构工时。

交付时区分实际改动、实际验证与剩余条件。不能将历史作者环境的通过记录、进程存在、一个空成功回执或旧快照解释为陌生用户端到端完成。
