# 可复制的 Agent 提示词

先提供本地源码或完整Windows分发包的位置。仅有Windows包时可完成已部署服务的桌面接入；若需要创建服务端或核对代码，另取得同版本源码ZIP，不能凭EXE猜测服务端参数。以下提示词让 Agent 读取同版本文档后工作；不要粘贴 App Secret、SSH 私钥或登录认证。Codex 和 Claude 都可以协助配置，当前模型批处理实现仅支持代码指定的 Codex CLI。

## 新用户安装并保存第一条原文

```text
请帮我安装并接入 Personal Time Logger。源码/Windows包的位置是：[填写我的本地绝对路径]。

先读取该版本 README 和 docs/SETUP.md、SERVER.md、CONFIGURATION.md、AGENT-SETUP.md，以及与当前步骤相关的实际代码。根据我的Windows环境和已有文件判断是新装还是升级，不假设存在作者配置。只使用我自己的飞书应用、服务器与账号，不查找或复制维护者部署、业务库或凭据。

目标是通过Windows入口进入软件，完成自己的设备登记，保存我明确授权的一条时间记录并看到服务器保存回执。最小流程先保持模型/Base/Notion派生功能关闭；离线队列不冒称完整本地账本。有可回退的本地配置工作就直接完成，不停在方案。需要我提供服务器、登录、审批或确认可信主机公钥时，每次只给一个具体步骤和完成标志。

保留现有device.json、Credential Manager和~/.personal-time-logger队列；发现旧数据但配置缺失时暂停重绑，先定位原配置。Secret只通过我的本机受限配置填写，不在聊天或输出中回显；桌面私钥只进Windows Credential Manager，服务器只收公钥。

测试、试运行、构建、额外校验，以及真正启动自己的服务或发送记录前，合并说明具体内容、原因、范围和是否写入数据，取得我的明确授权；不自行增加检查轮次。不自动注册模型任务、备份、Notion自动化或其他订阅。结束时说明实际改动、验证结果、未验证部分和当前仅一个必要的下一步。
```

## 在已有原文记录上配置模型和自己的Base

```text
我的Personal Time Logger已经能保存原文。请根据我提供的本地源码位置：[填写绝对路径]，接入我自己的模型解释与飞书Base。

读取docs/SERVER.md、CONFIGURATION.md、AGENT-SETUP.md及remote_worker.py、model_runner.py、base_adapter.py、service.py。先保留现有原文/设备/修订/outbox，不迁库或重绑。按代码核对Codex CLI版本、模型可用性与SSH配置；Claude若作为安装Agent，不要声称可直接用Claude做当前解释器。

使用我自己的受限配置，不复用作者的Base token、表ID、项目或登录态。先读取目标表实时schema，列出固定字段名/类型/已有选项的实际差异；不要新建分类、改表结构或写公式。未知起止/评分/AI比例留空，不把后台等待算人工。原文保存、模型导入与Base写后回读分别验收。

完成可回退的本地配置后，一次说明计划运行与验证范围，以及是否会真实写Base；获我授权后仅执行约定轮次。需要登录或权限审批时，每次只给一个当前步骤与完成标志。不要自动创建计划任务、备份或Notion流程。交付区分完成事实、实际验证和剩余条件，不以模型文字输出代替正式记录回读。
```

## 故障排查且保留原记录

```text
请排查我的Personal Time Logger：[一句话描述现象]。本地文件位置：[填写绝对路径]。

读取同版本SETUP/SERVER/CONFIGURATION及相关代码，以当前错误类别和目标文件为依据。保留原配置、原数据根、稳定提交ID、正文/时刻、草稿、Credential Manager和模型outbox。先区分本机保存、服务端保存、镜像、模型、Base核验中的失败阶段；不要重新发送已确认保存的内容，不删除队列或关闭主机公钥校验。

完成授权内的可回退修复。额外测试/试运行/构建/校验先说明范围、原因并取得我的授权；涉及服务器重启、真实记录/表结构修改或凭据重建时明确具体影响。需要我行动时只给一个当前步骤和完成标志。最后说明已证实原因、仍属推断的部分、实际改动和未验证范围。
```
